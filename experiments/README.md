# Сохранённые эксперименты

- [plugin-connection](plugin-connection/README.md): отдельный исходный снимок опытов с подтверждением подключения и удалением плагина. Он сохранён для истории разработки и не заменяет автоматически `home-control/`.

Здесь нет рабочих токенов, доказательств подключения или живого состояния сервера. Эксперимент не устанавливается и не публикуется в ChatGPT при клонировании репозитория.
