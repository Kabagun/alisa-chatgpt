# ChatGPT Voice на Станции

Нативный клиент для колонки с уже доступным root ADB и работающими штатными сервисами Алисы. Основан на [hu553in/yandex-station-chatgpt-voice](https://github.com/hu553in/yandex-station-chatgpt-voice); происхождение кода описано в [общих уведомлениях](../THIRD_PARTY_NOTICES.md).

## Возможности

- «Яндекс» запускает разговор ChatGPT; штатная Алиса сохраняет приоритет.
- Опциональный `--activation-command` позволяет использовать распознанную Али­сой команду. Сценарий настраивается владельцем отдельно.
- `--project-id` выбирает проект ChatGPT, `--led-feedback` включает экспериментальную индикацию.
- Один стартовый запрос предлагает Voice коротко заговорить. Он появляется в истории как обычная пользовательская реплика.
- Минута тихого ожидания завершает сеанс. Явно известное состояние ответа или работы инструмента приостанавливает таймер; нераспознанное окончание такого состояния может продлить сеанс.
- Приём Opus имеет ограниченное переупорядочивание и попытки FEC. Они не устраняют причину сетевых потерь.

Клиент работает на Станции, компьютер во время разговора не требуется. Протокол веб-Voice неофициальный и может измениться. Поддержка конкретной модели, прошивки, проекта и доступности аккаунта проверяется на своей установке. Здесь нет прошивок, vendor-библиотек, wake-моделей и готовых токенов.

## Подготовка и сборка

Нужны Linux или WSL, Go по версии из `go.mod`, Python 3, make, uv, pkg-config, C-компилятор, curl, tar и Android platform-tools. Для host-тестов нужна библиотека Opus. `tools/build-arm.sh` использует закреплённый Zig и собирает ARM Opus. Путь сборки не должен содержать пробелы.

Root-доступ — отдельная предпосылка; соответствующий upstream: [yandex-station-root](https://github.com/hu553in/yandex-station-root). До запуска выбери **Алиса** штатным словом активации в приложении устройства, чтобы «Яндекс» мог использовать локальный клиент.

Из этого каталога:

```sh
cp config.example.mk config.mk
# Задай STATION_IP в локальном config.mk.
make setup
make connect
make install
make auth
make start
```

`make auth` принимает собственный веб-токен скрытым вводом или из локального JSON через `SESSION_JSON`. OpenAI API key здесь не используется. Не вставляй токен в командную строку, исходник или Git. Процедура получения веб-токена и совместимость с сервисом зависят от текущего веб-клиента; смотри upstream-документацию. Для замены токена выполни `make auth`, затем `make restart`.

Стандартный helper устанавливает файлы в `/data/yandex-station-chatgpt-voice/`. Альтернативные схемы запуска из `../support/` рассматриваются отдельно и не включаются этой командой автоматически.

## Настройки

`config.mk` игнорируется Git. Образец содержит только переносимые параметры. Голос и overrides backend передаются как есть; их принятие определяет веб-сервис. Не делай выводов о лимитах аккаунта по настройке модели.

Дополнительные параметры доступны напрямую:

```sh
client run --help
client run --project-id=g-p-00000000000000000000000000000000 --led-feedback
```

Нулевой идентификатор выше — синтетический пример, его нужно заменить локально. Идентификаторы проекта и собственные настройки не хранятся в Git.

## Проверка

```sh
make check
make build
```

Офлайн-проверки используют синтетический звук и локальную передачу SRTP. Проверки прав файлов должны выполняться на POSIX-файловой системе: каталог проекта на DrvFs может не обеспечивать нужные права. Реальный микрофон и домашние устройства тестируются отдельно с разрешения владельца.

Стабильность речи и распознавание начала обращения всё ещё требуют проверки на целевой колонке. Счётчик опустошения буфера включает естественное окончание ответа; попытка FEC не означает, что отправитель прислал данные восстановления. Диагностика хранит ограниченные числовые показатели, не записи речи.
