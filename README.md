# Alisa

Наработки для ChatGPT Voice на Яндекс Станции и отдельного сервера умного дома.

| Каталог | Содержимое |
| --- | --- |
| [station](station/README.md) | Нативный Go-клиент колонки: слово «Яндекс», приоритет Алисы, звук, подсветка, завершение ожидания и маршрутизация в проект ChatGPT. |
| [home-control](home-control/README.md) | Сервер MCP/OAuth и интеграция Dreamehome: устройства, состояние, карты и управление в пределах предоставленных разрешений. |
| [support](support/README.md) | Шаблоны запуска и вспомогательные диагностические инструменты. Эксперименты отделены от основного клиента. |
| [docs](docs/ARCHITECTURE.md) | Архитектура, статус, правила хранения данных и пример инструкций голосового проекта. |

Клиент колонки работает на самой Станции; компьютер нужен для сборки, первоначальной настройки и обслуживания. Сервер умного дома — отдельный компонент, который можно разместить на своём сервере. Подключение MCP к конкретному режиму ChatGPT требует отдельной проверки.

Проект экспериментальный. Стабильность звука, распознавание первой реплики и совместимость с изменениями веб-протокола требуют проверки на целевом устройстве. Автоматические тесты не заменяют разговор с настоящей колонкой. Состояние компонентов описано в [STATUS.md](docs/STATUS.md).

Начинай с инструкции нужного компонента. Все адреса, ключи и параметры аккаунта задаются локально; готовых учётных данных и образов прошивки здесь нет. [Что исключается из Git](docs/PRIVACY.md).

Происхождение кода и отдельные лицензии приведены в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Общая лицензия на все компоненты не назначена.
